# 티어 문양 이미지

이 폴더에 아래 이름의 PNG를 넣으면 게임이 그 이미지를 문양으로 쓴다. 없는 티어는 기본(육각 메달) 문양을 쓴다.

| 파일 이름 | 티어 |
|---|---|
| bronze.png | 브론즈 |
| silver.png | 실버 |
| gold.png | 골드 |
| platinum.png | 플래티넘 |
| diamond.png | 다이아 |
| master.png | 마스터 |
| grandmaster.png | 그랜드마스터 |
| challenger.png | 챌린저 |

- 투명 배경 PNG, 가로세로 같은 비율(512×512 권장), 파일 하나 300KB 이하 권장.
- 다른 게임의 문양을 베끼거나 살짝 바꾼 그림은 넣지 않는다(CLAUDE.md 규칙).

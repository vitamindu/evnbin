# 04 Visual & Audio

## 아트 방향
- 밝은 카툰풍 3D. 3단 명암(toon) 재질 + 짙은 남색 외곽선(`#12102a`).
- 캐릭터는 머리가 큰 2.5~3등신, 실루엣과 색만으로 역할이 구분돼야 한다.
- 지금 캐릭터는 **스켈레톤(기본 도형 조합)** 이다. 최종 모델은 glTF로 교체하며, `FighterModel` 인터페이스(`update`, `celebrate`)만 지키면 된다.

## 카메라
| 장면 | 설정 |
|---|---|
| 로비 | FOV 26°, 정면 약간 위에서, 캐릭터 화면 중앙 |
| 캐릭터 상세 | FOV 26°, 캐릭터를 화면 오른쪽(가로 70% 지점) |
| 전투(2단계) | 고정 원근 카메라, 약 55° 내려다봄, 내 캐릭터를 따라감 |

## 색
| 용도 | 색 |
|---|---|
| 외곽선/잉크 | `#12102a` |
| 로비 배경 | 파랑 방사형 그라데이션 + 회전하는 빛줄기 + 점 무늬 |
| 타이틀 배경 | 노을(노랑→주황→빨강→자주) |
| 주요 버튼(PLAY/SELECT) | 주황 `#ff8a1f` |
| 선택됨 | 초록 `#48d16a` |
| 강조 | 노랑 `#ffd34d`, 하늘 `#63dcff` |
| 캐릭터 | RIVET 주황·청록 / VOLLEY 하늘·남색 / BOULDER 초록·돌회색·노랑 |

## 글자
- 영문: **Lilita One** (Google Fonts, OFL). 한글: **Black Han Sans** (OFL). 둘 다 게임 파일에 포함(오프라인 가능).
- UI 문구는 영어 대문자 위주. 모든 글자에 남색 외곽선 + 아래 그림자(`.t-outline`).

## UI 규칙
- 설계 기준 1280×800(태블릿 2560×1600의 절반). `#ui`가 화면에 맞게 확대·축소된다.
- 버튼: 3px 외곽선, 위쪽 하이라이트, 아래 5px 그림자, 누르면 3px 내려감.
- 손가락 대상 최소 크기 56px(설계 좌표).
- 아이콘은 `src/ui/icons.ts`의 직접 그린 SVG.

## 애니메이션
- 캐릭터 대기: 몸 위아래 흔들림, 호흡, 머리 좌우. 캐릭터마다 속도가 다르다.
- 선택 시: 짧은 점프 + 한 바퀴 회전(0.7초).
- 화면 요소: 로고 튀어나옴, 팝업 확대 등장, 알림 위로 사라짐.

## 사운드
- 지금은 WebAudio로 합성한 임시 효과음(탭, 뒤로, 선택, 시작).
- 5단계에서 실제 효과음·배경음으로 교체. 무료(CC0) 음원 또는 직접 제작.
- 첫 터치 전에는 소리를 낼 수 없다(브라우저 정책) → 타이틀의 첫 탭에서 잠금 해제.

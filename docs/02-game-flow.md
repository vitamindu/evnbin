# 02 Game Flow

```
타이틀(로그인 자리) ──탭──▶ 로비 ──PLAY──▶ 매칭 ──▶ 전투 ──▶ 결과 ──▶ 로비
                             │
                             ├─FIGHTERS / 캐릭터 탭──▶ 캐릭터 목록 ──▶ 캐릭터 상세(선택)
                             └─톱니바퀴──▶ 설정
```

## 1. 타이틀 (구현됨)
- 로고, 캐릭터 3명 대기 동작, 로딩 바 → `TAP TO START`.
- 첫 탭에서: 소리 잠금 해제, 전체화면 요청, 가로 고정. (브라우저는 사용자 터치 안에서만 허용)
- 로그인은 4단계에서 이 화면에 붙인다(게스트/계정).

## 2. 로비 (구현됨)
| 위치 | 요소 | 동작 |
|---|---|---|
| 왼쪽 위 | 프로필 카드(→ 프로필 창: 가장 많이 쓴 파이터, 프로필 사진·닉네임, 티어 점수), 티어 카드(→ 티어 안내) | 동작 |
| 오른쪽 위 | 코인, 크리스탈, 설정 | 설정만 동작 |
| 왼쪽 | 상점(→ 상점 화면) / 캐릭터 / 상자(→ 파이터 상자) | |
| 오른쪽 | 친구 / 파티(준비 중) / 길드(→ 길드 화면) | |
| 가운데 | 이름표, 선택한 캐릭터(드래그로 회전, 탭하면 목록) | 동작 |
| 가운데 양옆 | 파티 초대 슬롯(+) | 준비 중 |
| 아래 | SEASON PASS, 모드 카드, PLAY | PLAY만 동작(매칭 화면) |

준비 중인 버튼은 `COMING SOON` 알림을 띄운다.

## 3. 캐릭터 목록 / 상세 (구현됨)
- 목록: 카드(초상화, POWER, 트로피, 역할), 현재 선택은 노란 테두리 + `SELECTED`.
- 상세: 왼쪽 설명·스탯 막대·공격/궁극기, 오른쪽 3D 모델(드래그 회전, 좌우 화살표로 넘기기), `SELECT` 버튼.
- 선택은 기기에 저장되고 로비에 바로 반영된다.

## 4. 매칭 (임시 화면)
- 팀 슬롯 3대3, 경과 시간, 취소. 3단계에서 서버 매칭 상태로 바뀐다.

## 5. 전투 / 6. 결과 (2~3단계)
- 전투 HUD: 왼쪽 아래 이동 조이스틱, 오른쪽 아래 공격 조이스틱, 그 위 궁극기 버튼, 위쪽 점수·시간.
- 결과: 승/패, 트로피 변화, 다시 하기/로비.

## 화면 방향
- 가로 전용. 세로로 돌리면 `ROTATE YOUR DEVICE` 안내가 화면 전체를 덮는다.

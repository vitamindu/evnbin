# 06 Test Cases

자동 테스트는 `tests/`(Playwright), 실기기 확인은 아래 체크리스트. 기준은 이 설계 문서다.

## 1단계: 타이틀 · 로비 · 캐릭터 선택

### 자동 테스트 (뷰포트 1280×800, 터치)
| ID | 시나리오 | 기대 결과 |
|---|---|---|
| T-01 | 첫 실행 | 로딩 막대 → `TAP TO START`, 콘솔 오류 없음 |
| T-02 | 타이틀 탭 | 로비로 이동, 이름표에 기본 캐릭터 RIVET |
| T-03 | FIGHTERS 버튼 | 캐릭터 목록, 카드 3장 + MORE SOON, RIVET에 SELECTED |
| T-04 | VOLLEY 카드 → SELECT | 버튼이 SELECTED로 바뀜, 알림 표시 |
| T-05 | 뒤로 두 번 | 로비 이름표가 VOLLEY |
| T-06 | 새로고침 후 타이틀 탭 | 선택 유지(VOLLEY) |
| T-07 | 상세 화면 좌우 화살표 | 캐릭터가 순환(RIVET→VOLLEY→BOULDER→RIVET) |
| T-08 | 준비 중 버튼(SHOP, NEWS, FRIENDS, PARTY, CREW, 패스, 모드, +) | `COMING SOON` 알림, 화면 이동 없음 |
| T-09 | PLAY → CANCEL | 매칭 팝업 열림, 시간 증가, 취소하면 닫힘 |
| T-10 | 설정 → GRAPHICS / SHOW FPS | 값 전환, FPS 표시 나타남 |
| T-11 | 로비 캐릭터 탭 | 캐릭터 목록으로 이동 |
| T-12 | 세로 화면(800×1280) | `ROTATE YOUR DEVICE` 덮개 |
| T-13 | 짧은 화면(1280×712, 주소창 보임) | 버튼이 서로·화면 밖으로 겹치지 않음 |
| T-14 | PWA | `manifest.webmanifest`에 fullscreen·landscape·아이콘 192/512, 서비스 워커 등록 |

### 실기기 체크리스트 (Galaxy Tab S9 FE+)
- [ ] 크롬에서 열기 → 메뉴 → **홈 화면에 추가** → 아이콘으로 실행 시 주소창 없이 가로 전체화면
- [ ] 설정 팝업 아래 기기 정보가 `1280×800 @2x (2560×1600)` 근처인지
- [ ] SHOW FPS 켜고 로비 60fps 이상(가능하면 90)
- [ ] 캐릭터 드래그 회전이 손가락을 잘 따라오는지, 버튼 누름 반응
- [ ] 첫 탭 이후 효과음이 나는지
- [ ] 비행기 모드에서 다시 실행해도 열리는지(오프라인 캐시)
- [ ] 화면 회전·앱 전환 후 돌아왔을 때 정상

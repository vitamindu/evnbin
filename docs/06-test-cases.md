### 자동 테스트 (`tests/phase2.spec.ts`, 뷰포트 1280×800, 터치)
- 주소에 `?qa`를 붙여 `window.__fgBattle`(BattleSession)로 상태를 읽는다. `sim.step`을 감싸 틱마다 사건과 플레이어 상태를 기록한다(관찰만).
- 터치는 CDP `Input.dispatchTouchEvent`로 실제 터치·포인터 이벤트를 만든다(멀티터치 포함).
- 테스트 레버(상태 직접 조작): 순간이동(`player.pos`), 궁극기 게이지(`player.superCharge`), 탄창 비우기, 체력 1로 만들기, 더미 회복 잠시 멈춤. 나머지는 실제 입력으로만 조작한다.
- swiftshader에서는 시뮬레이션이 실제 시간보다 느리게(초당 약 10~17틱) 돌므로 시간 대신 틱·상태를 기다린다.

### 실기기 체크리스트 (Galaxy Tab S9 FE+, 전투)
- [ ] 이동 조이스틱: 왼쪽 아무 곳이나 눌러도 바로 나타나고, 손가락을 따라오는 느낌이 자연스러운지(늦거나 튀지 않음)
- [ ] 공격: 짧게 탭하면 바로 발사, 끌면 조준선이 손가락 방향과 정확히 맞는지, 가운데로 되돌리면 취소되는지
- [ ] 궁극기: 덜 찼을 때 회색 + 흔들림, 가득 차면 빛남이 잘 보이는지
- [ ] 멀티터치: 왼손으로 계속 움직이면서 오른손으로 조준·발사, 궁극기 조준이 끊기지 않는지(두 손가락 동시에)
- [ ] 화면 가장자리(제스처 영역) 근처 터치에서 브라우저 뒤로 가기·스크롤·확대가 일어나지 않는지
- [ ] 설정의 SHOW FPS를 켜고 전투 중 60fps 이상(가능하면 90), 벽 부수기·피해 숫자 많을 때도 크게 떨어지지 않는지
- [ ] 진동: 터치로 발사할 때 짧게 진동하는지(지원 기기), 너무 강하거나 계속 울리지 않는지
- [ ] 소리: 발사·적중·쓰러짐·궁극기 충전음이 나는지(첫 탭 이후)
- [ ] 머리 위 체력 막대·피해 숫자가 캐릭터를 따라가며 떨리지 않는지
- [ ] 쓰러짐 → 카운트다운 → 부활이 자연스러운지, 뒤로 버튼으로 로비에 돌아온 뒤 다시 들어가도 정상인지

# FIGHT GUYS 설계 문서

FIGHT GUYS(임시 이름)는 탑다운 3대3 팀 슈터 장르의 **오리지널 게임**이다. 장르의 일반적인 메커니즘은 참고하되, 이름·캐릭터·그래픽·사운드·UI 디자인은 모두 이 프로젝트에서 새로 만든다. 다른 게임의 고유 요소(이름, 캐릭터, 아트, 사운드, 모드·아이템 고유 명칭)를 복제하지 않는다.

|---|---|---|
| [01 Core Mechanics](01-core-mechanics.md) | 핵심 규칙, 승패 조건, 캐릭터·공격 체계 | Gameplay |
| [02 Game Flow](02-game-flow.md) | 타이틀 → 로비 → 매칭 → 전투 → 결과 흐름 | UI |
| [03 Physics & Controls](03-physics-controls.md) | 이동, 충돌, 조작, 입력 판정 | Gameplay, World |

| [06 Test Cases](06-test-cases.md) | 기능별 테스트 시나리오와 기기 확인 목록 | QA |

## 진행 단계

| 단계 | 범위 | 상태 |
|---|---|---|
| 1 | 프로젝트 구조, 타이틀(로그인 자리), 로비, 캐릭터 3종 선택 | **완료 (v0.1.0)** |
| 2 | 전투 오프라인: 맵, 이동, 공격, 궁극기, 연습장 + 4번째 캐릭터 HINAKO | **완료** |
| 3 | 실시간 온라인 대전: 게임 서버, 매칭, 동기화 | 예정 |
| 4 | 로그인·계정, 진행도 서버 저장 | 예정 |
| 5 | 최종 아트·사운드 교체, 캐릭터·모드 추가 | 예정 |

문서의 수치는 모두 **초안**이며, 플레이 테스트 후 바뀌면 문서를 먼저 고친 뒤 코드(`src/data/`)를 맞춘다.

# 03 Physics & Controls

> 이 장르에는 점프가 없다. 모든 게임 로직은 **평면(2D) 위에서** 계산하고, 3D는 보여주기만 한다.

## 단위
- 거리: **타일**(맵 격자 1칸 = 월드 1유닛). 시간: 초. 각도: 도(데이터) / 라디안(코드).
- 캐릭터 충돌체: 원, 반지름 0.4타일(BOULDER 0.5, 초안).

## 이동 (초안)
| 항목 | 값 |
|---|---|
| 이동 속도 | 캐릭터별 2.8~3.0 타일/초 (`moveSpeed`) |
| 가속 | 없음(즉시 최고 속도), 멈출 때도 즉시 |
| 대각선 | 조이스틱 방향 그대로, 속도 동일 |
| 벽 | 원 vs 사각 타일 충돌, 벽을 따라 미끄러짐 |
| 물 | 이동 불가, 투사체는 통과 |
| 수풀 | 이동 가능, 안에 있으면 은신 |

## 투사체
- 투사체도 원(반지름 0.15~0.3). 매 틱 이동 거리만큼 스윕 판정(빠른 탄이 벽을 뚫지 않게).
- 사거리에 도달하면 소멸. `lob`은 시작점→목표점 포물선, 착탄 시 범위 판정.

## 조작 (터치, 2단계 구현)
| 입력 | 동작 |
|---|---|
| 화면 왼쪽 절반 아무 곳 누르기 | 그 자리에 이동 조이스틱 생성(플로팅) |
| 이동 조이스틱 반경 | 설계 좌표 80px, 데드존 12% |
| 오른쪽 공격 버튼 **짧게 탭** | 사거리 안 가장 가까운 적에게 자동 조준 발사 |
| 공격 버튼 **드래그** | 조준선 표시, 손을 떼면 그 방향으로 발사 |
| 드래그를 버튼 중앙으로 되돌림 | 발사 취소 |
| 궁극기 버튼 | 공격 버튼과 같은 방식(게이지 찼을 때만) |

- 자동 조준과 수동 조준의 경계: 손가락 이동 20px(설계 좌표).
- 멀티터치: 이동·조준을 동시에. 각 손가락은 pointerId로 추적한다.
- 탭 판정: 누른 뒤 8px 미만 이동 + 250ms 이내.

## 로비에서 이미 쓰는 입력 (1단계)
- 캐릭터 드래그 회전: 가로 이동 1px당 0.012라디안. 손을 떼면 기본 방향으로 돌아감.
- 드래그 8px 미만이면 탭으로 처리.

## 시뮬레이션 주기
- 서버(3단계): 30틱/초 고정 시뮬레이션, 클라이언트로 상태를 20회/초 전송(초안).
- 클라이언트: 화면은 기기 주사율(최대 90Hz)로 그리고, 서버 상태 사이를 보간(100ms 지연).
- 내 캐릭터 이동은 입력 즉시 예측해서 움직이고, 서버 결과로 보정한다.
